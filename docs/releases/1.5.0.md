# Spotter 1.5.0 release verification

Status: annotated `v1.5.0` pushed; container images and GitHub Release published
and verified. The tag points to `e697298ed2e5449196892d0b37bf992a21c8beb3`.
Previous release: `v1.4.0`.

## Scope and upgrade

- App-style Back navigation: main tabs return to Workout, detail/editor screens
  return to logical parents, and guide/picker/confirmation/day-swap dialogs close
  first. Tab changes do not create a chronological Back trail.
- Shared full exercise guide for template and pre-start workout previews,
  including instructions, comments, primary muscles, demonstration, and ×.
- App-wide tap-highlight suppression with visible themed keyboard focus,
  spacing above Add exercise, and ten-second toasts centered on portrait phones.
- No SQLite migration, IndexedDB upgrade, API change, or dependency change.
  Keep `/data` and browser site data, including pending synchronization.
  Older upgrades crossing `1.2.0` still apply its approved secondary-muscle cleanup.
- Actual app exit remains controlled by the phone/browser. Older browsers without
  Navigation API support may retain pre-update history before the new root.
  Physical Android system exit has not been verified on a device.
- The trusted single-user deployment and previously documented dependency
  limitations remain unchanged. Verification uses only disposable synthetic data.

## Local verification

- Clean `npm ci` in an isolated source copy using the installed Node headers
  through `npm_config_nodedir`.
- `npm run check`: formatting, lint, TypeScript, 101 unit/integration tests,
  9 release-metadata tests, and production builds.
- All 27 Playwright browser tests against the production build, including
  phone/desktop layouts, both themes, keyboard focus, touch controls, guide
  content/dismissal, ten-second toast timing, logical Back parents, legacy tab
  history, modal reloads, offline recovery, and duplicate prevention.
- `docker build --build-arg APP_VERSION=1.5.0 --build-arg
GIT_COMMIT=release-candidate --tag spotter:1.5.0-release-candidate .`.
- Disposable mounted-volume checks: health/version, PWA/manifest, built-in
  muscles, exercise/template/history writes, GIF retention, idempotent replay,
  container replacement, stopped-volume backup/restore, SQLite integrity and
  foreign keys, and unchanged migrations one and two all passed.
- Privacy review covers the complete changed/new files and public release
  documentation; the effective author/committer identity is GitHub noreply.
  Third-party lockfile entries are unchanged.
