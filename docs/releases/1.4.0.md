# Spotter 1.4.0 release verification

Status: release candidate being validated; `v1.4.0` has not been created or
pushed. The previous release is `v1.3.1`. Current-version references in the
release source describe this candidate until publication is verified.

## Scope and upgrade

- Click-to-open, image-only exercise demonstrations in template details, the
  editor, and the pre-start workout cards; close button, outside click, and
  Escape dismissal, with keyboard focus restoration and offline cached media.
- Workout cards display muscle subheadings below exercise names, with Start
  above the cards. The Spotter icon resets the home selection to today without
  changing an in-progress workout.
- No SQLite migration, IndexedDB upgrade, API change, or dependency change.
  Preserve `/data` and browser site data, including pending synchronization.
  Older upgrades crossing `1.2.0` still apply its approved secondary-muscle cleanup.
- The trusted, single-user deployment and previously documented dependency
  limitations remain unchanged. No production data is used for verification.
